# Cross-Platform Utility Application

A Flutter-based mobile application developed to help users manage their daily notes and tasks through a simple and user-friendly interface.

## Features

- Add and manage personal notes
- Create and manage daily tasks
- View saved notes and tasks
- Simple and user-friendly interface
- Cross-platform development using Flutter

## Technologies Used

- Flutter
- Dart
- Android Studio
- Visual Studio Code

## Getting Started

Follow these steps to run the project:

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

   `flutter pub get`

4. Start an Android emulator or connect an Android device.
5. Run the application:

   `flutter run`

## Testing

The project was checked using Flutter's analysis and testing commands.

- `flutter analyze`
- `flutter test`
